# NovaLeran — Interactive Physics Curriculum

NovaLeran is a modern, high-fidelity interactive physics learning platform designed for Cambridge & International Baccalaureate (IB) Physics curriculum. It features an interactive catalog of 25 comprehensive chapters across 5 core units with custom vector scientific artwork, formula references, real-time physics simulators, and self-assessment quizzes.

## Curriculum Overview

The platform covers 25 core chapters structured across 5 visual learning paths:

1. **Space, Time and Motion**:
   - Kinematics
   - Forces and Newton's laws
   - Work, energy and power
   - Linear momentum
   - Rigid body mechanics
   - Relativity

2. **The Particulate Nature of Matter**:
   - Thermal energy transfers
   - The greenhouse effect
   - The gas laws
   - Thermodynamics
   - Current and circuits

3. **Wave Behaviour**:
   - Simple harmonic motion
   - The wave model
   - Wave phenomena
   - Standing waves and resonance
   - The Doppler effect

4. **Fields**:
   - Gravitation
   - Electric and magnetic fields
   - Motion in electric and magnetic fields
   - Electromagnetic induction

5. **Nuclear & Quantum Physics**:
   - Atomic physics
   - Quantum physics
   - Nuclear physics
   - Nuclear fission
   - Nuclear fusion and stars

## Key Features

- **Full-Bleed Vector Card Art**: Every chapter card features custom-crafted vector scientific artwork (such as the $x$-$t$ displacement curve with instantaneous velocity tangent and glowing point for Kinematics).
- **Interactive Physics Labs**: Built-in simulators including ballistic projectile motion, wave superposition, Hertzsprung-Russell (H-R) stellar diagrams, and radioactive half-life decay.
- **Formula Sheets & Summaries**: High-yield equation sheets and conceptual summaries for every chapter.
- **Practice Quizzes**: Checkpoint questions with explanations and instant feedback.
- **Search & Filter**: Real-time filtering by unit and keyword search across all 25 chapters.

## Getting Started

Open `index.html` directly in any modern browser, or launch a local web server:

```bash
# Using Python
python -m http.server 8000

# Open in browser
http://localhost:8000
```
